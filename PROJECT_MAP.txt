1. PROJECT OVERVIEW
================================================================================

Hear-Py is an AWS Lambda-backed Alexa skill that lets users:

  - Discover and play audio content (news, podcasts, community recordings)
  - Search by creator, organization, category, or topic
  - Browse trending content ("what's trending")
  - Browse local community content ("what's on near me")
  - Rate tracks (enjoyed / somewhat / not enjoyed)
  - Follow/unfollow creators
  - Report inappropriate content or creators
  - Enable/disable push notifications for new content
  - Control playback speed, seek, skip, pause, resume, next, previous
  - Receive onboarding for new users (location permissions, town capture)

The skill uses Alexa's AudioPlayer interface for long-form audio streaming.
The backend API (Hear API) handles search, content resolution, feedback,
location resolution, and notification subscriptions.

Runtime: Python 3.x on AWS Lambda
Framework: ask-sdk-core (Alexa Skills Kit SDK for Python)
AI/NLP: spaCy for entity recognition + local intent classification
Protocol: gRPC for optional remote NLU resolver (stubbed, not yet active)
Config: pydantic-settings for env-based configuration

3. ENTRY POINT -- main.py (201 lines)
================================================================================

FUNCTION: handler(event, context)
----------------------------------
The AWS Lambda handler. Entry point for ALL incoming events.

Flow:
  1. If event has requestContext.http  -> route to _webhook_router (HTTP webhook)
  2. If event has httpMethod == POST   -> route to _webhook_router (legacy)
  3. If event looks like Alexa request -> build skill, invoke skill handler
  4. If none of above                  -> return {"ok": True, "ignored": ...}
  5. On exception                     -> return last_resort_skill_response()

FUNCTION: _build_skill()
-------------------------
Lazily constructs the Alexa CustomSkillBuilder once per cold start:
  - Registers 40+ request handlers (intents, audio, feedback, notifications)
  - Registers 5 global request interceptors (LambdaDeadline, LoadPersistence,
    NotificationMiddleware, NlpInterceptor, LocalityGate, Confirmation)
  - Registers 1 global response interceptor (SavePersistence)
  - Sets DefaultApiClient
  - Returns the built skill object

FUNCTION: _webhook_router(event)
---------------------------------
Routes HTTP webhook requests:
  - Verifies x-webhook-secret header via verify_secret()
  - /webhook/settings   -> handle_settings_webhook()
  - /webhook/notification -> handle_notification_webhook()
  - Otherwise           -> 404

FUNCTION: _resolve_persistence_driver()
----------------------------------------
Resolves whether to use DynamoDB or in-memory persistence.
Uses HEAR_PERSISTENCE_DRIVER env var or falls back to DynamoDB if table set.

Factory function. Creates a DynamoDbPersistenceAdapter with configured
table, region, and TTL.

6. WEBHOOKS -- src/webhooks/
================================================================================

FUNCTION: verify_secret(event)
-------------------------------
Checks the x-webhook-secret HTTP header against WEBHOOK_SECRET config.
Returns a 401 response dict if invalid, None if authorized.

FUNCTION: dispatch(event_type, data, options)
-----------------------------------------------
Universal event dispatcher. Builds an envelope {event, timestamp, data}
and routes to either:
  - SQS queue (if SQS_OUT_QUEUE_URL is set)
  - HTTP endpoint (if WEBHOOK_OUTBOUND_URL is set)
Dispatched events include:
  playback.started, playback.stopped, playback.finished
  playback.nearly_finished, playback.event
  user.feedback_given, user.followed_creator, user.unfollowed_creator
  user.reported_content, user.reported_creator, user.location_updated
  notification.subscribed, notification.unsubscribed

FUNCTION: handle_settings_webhook(event)
-----------------------------------------
HTTP webhook endpoint at /webhook/settings. Writes global settings
(autoPlay, outroEnabled, outroUrl, feedbackEnabled) to DynamoDB table
hear_settings. Invalidates the in-memory cache after write.

FUNCTION: get_settings()
-------------------------
Fetches global settings from DynamoDB hear_settings table. Results are
cached in memory. Falls back to defaults if table unavailable.
Returns: {autoPlay, outroEnabled, outroUrl, outroUrlFinal, feedbackEnabled}

FUNCTION: invalidate_settings()
----------------------------------
Clears the in-memory settings cache so next read fetches fresh data.

FUNCTION: handle_notification_webhook(event)
-----------------------------------------------
HTTP webhook endpoint at /webhook/notification. Writes a notification
track to DynamoDB hear_notifications table. Uses conditional put to
prevent duplicates (attribute_not_exists on pk).

FUNCTION: check_notifications(user_id)
----------------------------------------
Scans DynamoDB hear_notifications for tracks where announcedTo does
NOT contain the given user_id. Returns list of track dicts.

FUNCTION: mark_track_announced(track_id, user_id)
--------------------------------------------------
Adds user_id to announcedTo string-set on a notification track.
Prevents re-announcing previously seen notifications.

FUNCTION: mark_track_heard(track_id, user_id)
-----------------------------------------------
Adds user_id to heardBy string-set on a notification track.
Tracks which notifications the user has actually listened to.

FUNCTION: mark_all_tracks_announced(track_ids, user_id)
--------------------------------------------------------
Batch wrapper. Calls mark_track_announced for each track_id.

FUNCTION: group_notifications_by_creator(tracks)
--------------------------------------------------
Groups notification tracks by their creatorId/creator.
Sorts groups by track count descending. Each group has:
  {creatorId, creatorName, tracks[]}

FUNCTION: build_notification_speech(groups)
---------------------------------------------
Builds the spoken Alexa intro for notifications from grouped tracks.
Uses NOTIFICATIONS_SINGLE_TRACK, NOTIFICATIONS_SINGLE_CREATOR,
or NOTIFICATIONS_MULTI_CREATOR speech templates.

FUNCTION: handler(event, context) -- outbound_consumer.py
-----------------------------------------------------------
Separate Lambda function. Consumes SQS messages and forwards each
event envelope to the outbound HTTP webhook with HMAC signing.

FUNCTION: sign_payload(payload, secret)
----------------------------------------
Signs a payload with HMAC-SHA256. Returns {signature, timestamp}
where signature = "t={ts},v1={hexdigest}".

FUNCTION: verify_signature(payload, signature_header, secret)
---------------------------------------------------------------
Verifies an HMAC-SHA256 webhook signature with timestamp tolerance
(configured by WEBHOOK_SIGNATURE_TOLERANCE_SECONDS, default 300s).
Uses constant-time comparison to prevent timing attacks.

FUNCTION: _constant_time_compare(a, b)
---------------------------------------
Constant-time string comparison. Used to prevent timing side-channels
during signature verification.

MODULE: persistence.py (654 lines -- THE BRAIN)
-------------------------------------------------
Manages ALL session state persistence:

  CLASS: LoadPersistenceInterceptor
    Request interceptor registered globally. At every request:
    - Skips persistence load for audio events under time pressure
    - Loads saved attributes from DynamoDB with time budget
    - Merges loaded data with DEFAULT_STORE via merge_initial_store()
    - Applies store migrations (_migrate_playback_fields)

  CLASS: SavePersistenceInterceptor
    Response interceptor registered globally. At every response:
    - Only saves if _dirty flag is True
    - Builds slimmed snapshot via build_persisted_snapshot()
    - Saves to DynamoDB with time budget
    - Handles reliable saves for critical state (feedback, onboarding)

  FEEDBACK STATE MACHINE:
    set_pending_feedback()          -- Stage feedback for current track
    clear_pending_feedback()        -- Remove pending feedback record
    clear_feedback()                -- Full feedback state reset

CLASS: NlpInterceptor (nlp/__init__.py, 314 lines)
----------------------------------------------------
GLOBAL request interceptor. At every IntentRequest:
  1. Extracts raw utterance from Alexa slots (priority-based selection)
  2. Checks if intent is gated for gRPC resolution (GATED_INTENTS)
     - If yes: tries gRPC resolver (currently non-functional)
     - If no: falls back to local classify_utterance()
  3. Handles slot value merging (creator, organization, topic, category)
     - Resolves names via wink_instance.resolve_name()
     - Handles "latest" prefix stripping
  4. Handles town capture override during onboarding
  5. Falls back to suggestions for unclear intents
  6. Attaches NLP result as _nlp on request attributes:
     {intent, alexaIntent, alexaRawIntent, nlpMatchesAlexa,
      needsRedirect, confidence, slots}

FUNCTION: classify_utterance(raw) (nlp/classifier.py, 479 lines)
------------------------------------------------------------------
Rule-based intent classifier.

  1. Preprocesses text via preprocess_utterance() (spaCy)
  2. Detects category (from DynamoDB entity data + stems)
  3. Detects multi-word categories (e.g. "talking newspaper")
  4. Detects creator from spaCy PERSON entities + custom entities
  5. Detects organization from spaCy ORG entities
  6. Detects city/location from spaCy GPE/LOC entities + DynamoDB cities
  7. Checks hint sets for intent routing:
     - TRENDING_HINTS -> "trending"
     - LOCAL_HINTS -> "local"
     - FOLLOWING_HINTS -> "following"
     - BROWSE_HINTS -> "browse"
     - MORE_HINTS -> "show_more"
  8. Fuzzy matches "from/by {name}" patterns to creators/organizations
  9. Resolves entity names via wink_instance.resolve_name()
  10. Builds residual query from unmatched tokens

  Returns: {intent, confidence ("high"/"low"), slots}
