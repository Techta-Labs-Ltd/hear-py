# API consumer map

This map records the externally observable operations currently called by this checkout. It is an inventory for contract review and deletion work, not evidence that any remote service accepts a changed contract.

| Entrypoint / feature | Owner and operation | Method and path | Request identity and schema | Timeout / retry / idempotency | Verification and migration status |
| --- | --- | --- | --- | --- | --- |
| Listener identity middleware | `HearApiClient.resolve_listener_identity` | `POST /alexa/listeners/resolve` without `HEAR_API_PATH_PREFIX`; `POST /listeners/resolve` with it | `ListenerPayload.resolution`: allowlisted `listenerId`, `alexaUserId`, `userEmail`; API key header | Request deadline supplied by identity middleware; no client retry; no operation ID | `tests/test_identity.py`, `tests/test_api_client.py`; retained because identity resolution is a production dependency. |
| Bootstrap/onboarding profile sync | `HearApiClient.sync_listener` | `POST /alexa/listeners/sync` without prefix; `POST /listeners/sync` with it | `ListenerPayload.registration`: `action=alexa`, Alexa ID, optional canonical listener/profile/location fields | Caller deadline; no retry; no operation ID | `tests/test_identity.py`, `tests/test_onboarding_completion.py`; distinct from registration until backend contract evidence says otherwise. |
| Bootstrap/onboarding registration | `HearApiClient.register_listener` | `POST /alexa/listeners/register` without prefix; `POST /listeners/register` with it | Same strict registration allowlist as sync | Caller deadline; no retry; no operation ID | `tests/test_identity.py`, `tests/test_api_client.py`; retained pending backend consumer/contract audit. |
| Search, browse, play and availability fallback | `ListenerBoundHearClient.search` / `HearApiClient.search` | `POST /alexa/search` without prefix; `POST /search` with it | `SearchPayload` maps query, page, limit, allowed sort/filter keys and immutable bound `alexaUserId`/`listenerId` | Request deadline; retries only transient transport, 429 and 5xx responses; `Retry-After` must fit remaining budget; no operation ID | `tests/test_api_client.py`, `tests/test_search_queue.py`, `tests/test_availability_flow.py`; retained. |
| Local/creator/organisation availability | `ListenerBoundHearClient.availability` / `HearApiClient.availability` | `POST /alexa/availability` without prefix; `POST /availability` with it | `SearchFilters.availability` validates the endpoint filter. `AvailabilityRequest` maps local inputs to search wire fields and bound identity. | Request deadline; same transient retry policy as search; no operation ID | `tests/test_api_client.py`, `tests/test_availability_flow.py`, `tests/test_search_request.py`; retained. |
| Resolver middleware | `ResolverClient.resolve` | `POST {HEAR_RESOLVER_URL}/resolve` | Resolver body includes utterance, timezone, country and optional identity; API key header | Caller deadline; no retry; anonymous-only copied cache; no operation ID | `tests/test_resolver_client.py`, `tests/test_reliability_foundation.py`; retained. |
| Notification inbox | `NotificationApiClient.pending` | `POST /alexa/notification` without prefix; `POST /{HEAR_API_PATH_PREFIX}/notification` with it | `operation=fetch`, listener ID, optional notification ID, purpose and bounded limit | Caller deadline; no client retry; 429/5xx/transport are returned as retryable; no operation ID | `tests/test_notifications.py`; retained. |
| Notification delivery status | `NotificationApiClient.update` | Same notification path | `operation=update`, listener ID, notification ID, status and bounded delivery result fields | Caller deadline; no client retry; 429/5xx/transport are returned as retryable; notification ID is the reconciliation key | `tests/test_notifications.py`; retained. |
| Alexa address permission flow | `AlexaSettingsClient.get_device_address` | `GET {apiEndpoint}/v1/devices/{deviceId}/settings/address` | Request-scoped Alexa API access token; response is reduced to allowed address fields | Deadline-aware timeout; no retry; not an application operation | `tests/test_alexa_device_address.py`, `tests/test_permission_flow.py`; retained. |
| Alexa account-settings profile flow | `AlexaSettingsClient.get_profile_setting` | `GET {apiEndpoint}/v2/accounts/~current/settings/{settingPath}` | Request-scoped Alexa API access token; profile value is normalized | Deadline-aware timeout; no retry; not an application operation | `tests/test_permission_flow.py`; retained. |
| Progressive speech | `ProgressiveResponseClient.send` | `POST {apiEndpoint}/v1/directives` | Request ID, `VoicePlayer.Speak` directive and request-scoped Alexa access token | One attempt; at most once per request; no operation ID | `tests/test_cards_and_progressive.py`; retained. |
| Durable outbound event relay | `SqsEventClient.send` | AWS SQS `SendMessage` to `SQS_OUT_QUEUE_URL` | Validated `BackendEventEnvelope` and allowlisted SQS attributes | Queue durability/retry is AWS-owned; stable `eventId` and `clientEventId` are generated before staging | `tests/test_outbound_events.py`, `tests/test_outbox.py`; deployment and backend-deduplication verification remain external. |
| Outbound webhook relay | `WebhookEventClient.send` | `POST WEBHOOK_OUTBOUND_URL` | Validated event envelope, signed body and API key headers | One worker attempt; worker record remains failed for redelivery; envelope ID is stable | `tests/test_outbound_events.py`, `tests/test_outbox.py`; retained while relay infrastructure is deployed. |
| Alexa proactive notification worker | `ProactiveNotificationClient.deliver` | OAuth token: `POST https://api.amazon.com/auth/O2/token`; event: `POST` Alexa stage-specific proactive-events endpoint | Client credentials for token; validated proactive event body for recipient Alexa user ID | Token cached before expiry; delivery returns retryability/status; notification ID is reconciled through notification update | `tests/test_notifications.py`; retained. |

The paths controlled by `HEAR_API_PATH_PREFIX` intentionally differ from the no-prefix Alexa paths. No endpoint should be removed, combined or renamed until this map, the deployed backend contract and all worker/interaction-model consumers agree.
